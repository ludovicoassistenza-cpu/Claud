# Claud — spazio di lavoro Codex Cloud

Repository di base per attività di sviluppo con Codex Cloud.

## Avvio

Selezionare questo repository nella creazione dell'ambiente Codex Cloud. Durante la configurazione verificare Bash, Git, Node.js, npm e Python 3, la scrittura nella cartella di lavoro e l'esecuzione di un programma minimo in JavaScript e Python.

Questo repository non contiene ancora un'applicazione né dipendenze di progetto. Aggiungere dipendenze e comandi di avvio quando viene definito il primo progetto. Non richiede chiavi API per la configurazione di base.

## Contenuti

- `AGENTS.md`: istruzioni operative per Codex.
- `.gitignore`: esclusione di credenziali locali, dipendenze e file temporanei.

L'ambiente cloud va pubblicato dopo la verifica della configurazione. Salvare il lavoro importante nel controllo di versione.
